# Designo

A responsive agency website built with Next.js, TypeScript, and Tailwind CSS, based on a Frontend Mentor design challenge.

## Features

- Responsive layouts for mobile, tablet, and desktop
- Reusable React components
- Mobile navigation menu
- Multiple pages for services, company information, and locations
- Contact form UI

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Lucide React

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone YOUR_REPOSITORY_URL
cd designo
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
